Review and clean up your transactions.

Moneyflow shows where your money goes and lets you fix merchants and categories hundreds of rows at a time. Nothing changes until you review and commit. Use it in a browser, in a terminal, or from an AI assistant.

InstallTry the demoRead the docs

What you can do

See where your money goes
Total your spending by merchant, category, account or month. Open any total to see the transactions behind it.
Fix many transactions at once
Rename a merchant or change a category across a whole selection. Undo any bulk edit in one step.
Check before anything changes
Edits wait until you review and commit them, and they survive a restart. Monarch and YNAB receive only what you commit.
Find anything
Search merchant and category names, narrow to one account or category, and pick any date range.
Keep your data
Each profile is a SQLite file in ~/.moneyflow. Export to Parquet, CSV or SQLite whenever you like.
Trust the totals
Amounts are stored as exact integers in each currency’s smallest unit, so totals never pick up rounding errors.

Use the interface you prefer

All three open the same profiles and share the same pending edits.

Browser

Charts and tables in a local browser tab, on a desktop or a phone. 

moneyflow web
Web guide

Terminal

Everything the browser does, from the keyboard. Works over SSH. 

moneyflow tui
Terminal guide

AI assistants

Ask Claude or another MCP client about your spending. It can stage edits only if you allow it, and you still review every commit. 

moneyflow mcp
MCP guide

Install and try the demo

Moneyflow is one binary for Linux, macOS and Windows. The demo uses about 2,000 made-up transactions and needs no account. Demo edits disappear when you quit.

For Windows, manual downloads and checksums, see Installation. Coming from Python Moneyflow? Read Moving to Go first. 

$ curl -fsSL https://github.com/wesm/moneyflow/releases/latest/download/install.sh -o install.sh
$ sh install.sh
$ moneyflow web --demo
$ moneyflow tui --demo
