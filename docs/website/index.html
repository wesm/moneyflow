Transaction review · browser, terminal, MCP

Review every transaction. Commit only what you meant.

Moneyflow groups, searches and bulk-edits your transactions. Every edit waits in a review queue until you commit it. Amounts are exact, your data stays in a local SQLite profile, and Monarch and YNAB changes leave your machine only after review.

One loop, two screens

The same keys in the browser and the terminal.

In the browser you can also point and click. The sidebar picks the view, checkboxes select rows, and the selection bar opens the editors.

  1. gGroup by merchant, category, group, account or time
  2. EnterDrill into the rows behind a total
  3. /Search merchant and category names
  4. SpaceSelect rows
  5. m cRename the merchant or change the category
  6. u UUndo or redo, one bulk edit at a time
  7. wReview every pending edit
  8. EnterCommit the reviewed changes

? lists the keys for the current view. Keyboard reference

What it does

Built for people who reconcile their own books.

Group and drill
Totals by merchant, category, group, account or time. Drill into any row and break it down by another dimension.
Search and filter
Regular-expression search over merchant and category names. Filters and periods narrow the view without changing data.
Bulk edits
Rename merchants, change categories, hide or delete rows across a whole selection. Each bulk edit is one undo step.
Review, commit, undo
Pending edits survive a restart. Review shows every affected row before you commit. If the profile changed, you review again.
Exact money
Amounts are signed integers in minor units with their currency and scale. No floating-point totals.
Local SQLite
Each profile is a SQLite database under ~/.moneyflow. Export to Parquet, CSV or SQLite at any time.

Try the demo

Synthetic data. No account.

The demo is a household of about 2,000 transactions. Edits are real but temporary: the demo profile is deleted when the process exits.

Install or build Moneyflow, then run either command. A source build puts the binary at ./bin/moneyflow. 

$ moneyflow web --demo
$ moneyflow tui --demo

Status

The Go application has no release yet.

These docs describe the Go application on main. Build it from source until a Go release appears on GitHub. The latest published release, Python 0.11.1 on PyPI, is the legacy application, documented in the Python archive.

Go-to-Go profile transfer works. The exporter that moves Python data into Go does not exist yet, so keep your Python data. Moving to Go lists what carries over.
